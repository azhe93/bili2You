# Bili2You - YouTube 视频加载 B 站弹幕

Bili2You 是一个 Chrome 扩展，用于在 YouTube 视频播放器上叠加显示对应 Bilibili 视频的弹幕。扩展通过 YouTube 频道与 B 站 UP 主的映射关系自动匹配视频，也支持在弹出面板中手动搜索和加载弹幕。

## 功能特性

### 弹幕同步

- 从 Bilibili 获取分段弹幕，并在 YouTube 播放器上实时渲染。
- 支持滚动弹幕、顶部固定弹幕和底部固定弹幕。
- 保留弹幕原始颜色，并使用用户设置控制字号、不透明度、速度、密度和显示区域。
- 支持视频播放、暂停、跳转和全屏场景下的弹幕同步。

### 视频匹配

- 支持建立 YouTube 频道到 B 站 UP 主的持久映射。
- 自动匹配时优先在已映射 UP 主的投稿中搜索；空间搜索无结果时再使用包含 UP 主名称的全站搜索作为回退，弹出面板会进一步按 UP 主 `mid` 过滤回退结果。
- 匹配逻辑会清理标题中的标签、括号和常见标点，并使用 OpenCC 做繁体到简体转换。
- 标题相似度采用词级或字符级 Jaccard 计算；匹配度达到 80% 时会直接加载弹幕。
- 手动模式下可以搜索 UP 主、搜索 B 站视频并选择要加载的弹幕源。

### 设置项

- 时间偏移：调整弹幕时间轴。
- 字体大小：12px 到 36px。
- 不透明度：10% 到 100%。
- 滚动速度：5 秒到 20 秒。
- 弹幕密度：25%、50%、75% 或全部。
- 屏幕高度：控制滚动弹幕可用区域，范围为 20% 到 100%。
- 显示开关：在当前播放页面显示或隐藏弹幕。

设置会先保存到 `chrome.storage.local`，再尽力同步到当前 YouTube 页面；页面暂时不可达时不会丢失设置。

## 安装方法

### 开发者模式安装

1. 下载或克隆此项目到本地。
2. 打开 Chrome 浏览器，访问 `chrome://extensions/`。
3. 开启右上角的开发者模式。
4. 点击加载已解压的扩展程序。
5. 选择项目文件夹。

无需构建步骤，直接加载即可使用。

## 使用方法

### 首次使用

1. 打开 YouTube 视频播放页。
2. 点击浏览器右上角的 Bili2You 扩展图标。
3. 搜索并选择对应的 B 站 UP 主，建立频道映射。
4. 扩展会根据当前 YouTube 视频标题匹配 B 站视频；高匹配度结果会自动加载，其他情况可以手动选择。

### 自动加载

- 建立频道映射后，访问该频道的视频时会自动尝试匹配和加载弹幕。
- 自动加载在视频开始播放后触发，以减少 YouTube 单页应用切换时的旧标题、旧频道信息干扰。
- 切换 YouTube 视频时，扩展会取消过期加载请求并清理旧弹幕，避免旧视频弹幕覆盖新视频。
- 即使两个视频标题相同，也会在短暂等待页面信息稳定后继续自动加载流程。

### 手动加载

1. 在弹出面板中点击更换 UP 主或更换视频。
2. 搜索并选择正确的 B 站视频。
3. 点击加载弹幕。
4. 如有时间轴差异，可在设置中调整时间偏移。

## 技术实现

### 架构概览

```text
YouTube 页面 Content Script
        |
        | chrome.runtime.sendMessage
        |
Background Service Worker
        |
        | fetch + WBI 签名
        |
Bilibili API

Popup UI 通过 Background 与 Content Script 通信
```

### API 调用

- 使用 Bilibili 搜索接口查找视频和 UP 主。
- 使用 Bilibili 视频信息接口获取 `aid`、`cid`、分 P 信息和时长。
- 使用 `seg.so` 分段弹幕接口获取 protobuf 格式弹幕。
- 通过 Background Service Worker 代理请求，避免内容脚本直接访问接口时遇到跨域限制。
- WBI 签名密钥缓存 30 分钟，请求失败时使用指数退避重试。

### 弹幕数据处理

- 按 6 分钟为一个分段请求弹幕。
- 内置轻量级 protobuf 解析器，解析 `DmSegMobileReply` 中的弹幕时间、模式、字号、颜色和内容。
- 对多段弹幕合并后按时间排序。
- 分 P 视频会根据 YouTube 标题与 B 站分 P 标题的相似度选择最合适的 `cid`。

### 弹幕渲染

- 使用 `requestAnimationFrame` 驱动渲染循环。
- 使用轨道记录滚动弹幕占用时间，减少重叠。
- 每帧最多发射 15 条弹幕，避免跳转或弹幕高峰时一次性创建过多 DOM。
- 固定弹幕显示 4 秒，滚动弹幕时长由用户设置控制。
- 活跃弹幕结束后会从 DOM 中移除。

### 状态管理

- `chrome.storage.local` 保存 UP 主映射、用户设置和当前视频加载状态。
- 内容脚本通过 `MutationObserver` 监听 YouTube 单页应用导航。
- background 为每个 tab 维护加载版本号，用于取消过期自动加载请求。
- popup 打开期间收到 URL 变化通知后会重新读取当前页面信息。

## 权限说明

| 权限 | 用途 |
|------|------|
| `storage` | 存储 UP 主映射、用户设置和当前视频状态 |
| `activeTab` | 获取当前活动标签页并向内容脚本发送消息 |
| `scripting` | 预留给扩展脚本注入能力 |
| `https://www.youtube.com/*` | 在 YouTube 播放页运行内容脚本 |
| `https://api.bilibili.com/*` | 调用 B 站搜索、视频信息和弹幕接口 |
| `https://comment.bilibili.com/*` | 兼容 B 站弹幕相关接口权限 |
